## How it works
Single standalone `public/index.html`, no backend. Deployed to Cloudflare Workers as static assets. Every push to `main` deploys automatically.

## Starting a new project from this template
1. On github.com, open `caseyhudetz/lab-template` and choose **Use this template**.
2. In the Cloudflare dashboard: Workers & Pages → Create → Import an existing Git repository → pick the new repo → Deploy. This also connects Workers Builds.
3. Open the repo in Claude Code and describe the app. `CLAUDE.md` handles the rest.
